# AGENTS.md

Rules for AI agents working in this repository.

## Git workflow

1. **No commit or push without human confirmation.** Always ask and wait for an explicit "yes" before running `git commit` or `git push`.
2. **One branch per change.** Create a new branch for each change and push to that branch. Never commit directly to `main`.
3. **Branch from `main`.** `main` is the main branch; every change must start from an up-to-date `main`.
4. **Open a PR only when needed.** Create a pull request once the change is ready for review, targeting `main`.
